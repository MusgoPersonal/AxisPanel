# AxisPanel

> [!abstract] Dashboard de Control
> AxisPanel es un dashboard Node.js (Express) con frontend Svelte para gestionar APIs de LLMs, scraping de leads, CRM, y agentes de IA.

## Stack

| Capa | Tecnología |
|------|-----------|
| Backend | Express.js (Node) |
| Frontend | Svelte + Vite |
| DB | better-sqlite3, JSON files |
| Auth | Firebase Admin + token compartido |
