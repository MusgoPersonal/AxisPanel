# Axis Panel Project

## Overview
This is a custom Node.js dashboard project, featuring a Svelte frontend. It integrates:
- API rotation UI
- Chat with Hermes
- CRM functionalities
- Web scraping capabilities

## Access
- The panel runs on port `3030`.
- The Hermes API for chat uses port `8642`.

## Location
The backend `server.js` is located at `C:\AxisPanel\`.

## Key Features
- **CloudShells + Firebase RTDB + agent.js workers**: For cloud-based worker processes.
- **Collapsible Sidebar**: Available on all pages of the dashboard.
